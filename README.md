# TrigVerse — Complete Interactive Trigonometry Quest

An interactive 24/7 web & mobile PWA for mastering Trigonometry from foundations to Class 11 & 12 mastery.

## Features
- **44-Chapter RPG Trigonometry Quest** with interactive boss battles & companions
- **Complete Formula Vault** from beginning to advanced identities
- **200 Bilingual Video Lectures** (English & Urdu/Hindi)
- **14 Interactive Touch Canvas Labs** (Unit Circle, Waves, Transformations & more)
- **Triangle & Trigonometry Solver**
- **Installable PWA + Offline Support** via Service Worker
